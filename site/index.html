A curated set of agent skills, installable on Claude Code, GitHub Copilot, Cursor, and other harnesses via APM.

Getting started

1. Install APM curl -sSL https://aka.ms/apm-unix | sh
2. Install every skill
or pick one below

Over SSH, single skills cannot be installed with a one-line command: copy the snippet into dependencies.apm in your project's apm.yml, then run apm install. Make sure your SSH key is loaded (ssh-add).
